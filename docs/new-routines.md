# New routines, draft for review

Every exercise name below matches an existing row in `exercises` on liftcamp-prod (checked 11 Sep 2026). Blurbs follow the app copy rules, so no em dashes and no colons.

Reps written as a range (8-10) mean pick a weight you can do for the low end and add reps until you hit the top, then add weight. "each" means per side.

## 6. Madcow 5x5 (recommend holding)

- Slug: `madcow-5x5`
- Level: Intermediate
- Days per week: 3
- Equipment bucket: Gym
- Blurb: The step after a beginner 5x5. Heavy Monday, light Wednesday, a new top set Friday, and the weight goes up once a week.

**Monday, heavy**

| Exercise | Sets x reps |
|---|---|
| Barbell Squat | 5 x 5, ramping to a top set |
| Barbell Bench Press | 5 x 5, ramping to a top set |
| Bent Over Barbell Row | 5 x 5, ramping to a top set |

**Wednesday, light**

| Exercise | Sets x reps |
|---|---|
| Barbell Squat | 4 x 5, stop at Monday's third set weight |
| Standing Military Press | 4 x 5, ramping |
| Barbell Deadlift | 4 x 5, ramping |

**Friday, new top set**

| Exercise | Sets x reps |
|---|---|
| Barbell Squat | 4 x 5 ramping, 1 x 3 new top, 1 x 8 back-off |
| Barbell Bench Press | 4 x 5 ramping, 1 x 3 new top, 1 x 8 back-off |
| Bent Over Barbell Row | 4 x 5 ramping, 1 x 3 new top, 1 x 8 back-off |

Why hold it: Madcow's whole identity is sets at different weights within one exercise. Even with target sets and reps in the database, the workout screen prefills the same weight for every set, so the app can't guide it yet. Ship it once templates support per-set targets.

## Changes to existing routines

- **5x5 Strength**: relabel Intermediate to Beginner. Linear 5x5 is a first-program format.
- **Days label**: the site shows "2 days" on Full Body 3x/week because it counts distinct workouts. Show workouts as "2 workouts" and make the Days a week filter use real training days (Full Body 3, Upper / Lower 4, PPL 3 or 6).

## Notes for the schema session

- **Goblet Squat is tagged `kettlebells`.** If equipment buckets are derived from exercises, treat kettlebells as dumbbells, or the two dumbbell plans land in Gym.
- **Target reps need a text column**, not an integer. Values include ranges (8-10), time (30s), and per-side (8 each).
- **Onboarding match after these land**:

  - Beginner + Dumbbells: Dumbbell Only, Dumbbell Upper / Lower
  - Beginner + No equipment: Bodyweight Only
  - Intermediate + Gym: Upper / Lower, PPL, PHUL, Glute Focus
  - Intermediate + Dumbbells: Dumbbell PPL
  - Intermediate + No equipment: nothing. Bodyweight Only is the only no-equipment plan. Show the closest match with a note, or add an intermediate bodyweight plan later.
