Everything no rule above claims, and a null or empty value. No live row has a null equipment today.
  • Rule order in equipmentIconKind is smith, ezbar, dumbbell, barbell, kettlebell, cable, machine, body, band, other. Matching is a lowercase substring test, so order is what keeps "smith machine" off the machine rule and "e-z curl bar" off the barbell rule.
  • smith and machine draw the same cog, and band and cable draw the same cable, on both platforms. They are separate kinds so a dedicated glyph can be added later without touching the mapping.
  • Sizes in use: the web renders 14px (h-3.5), 16px (h-4), 18px (h-4.5) and 20px (h-5) through Tailwind classes; mobile's EquipmentIcon renders at 18 in the info sheet. 24 is the authored size and is shown here for reference.
  • Barbell and EZ bar plates are open rounded rectangles rather than filled bars so they keep a hole at 14px, matching how the Lucide dumbbell heads hold their interior.
